# Project Multiverse — Lokraj Joshi

Standalone repository for the interactive Project Multiverse engineering identity portal.

The portal preserves the animated credential deck, interactive system worlds, cursor-reactive engagement signal, and Signal Runner entry point used by my profile.

## Experience map

| Surface | Purpose | Evidence |
| --- | --- | --- |
| Identity core | Introduces the LJ / Lokraj Joshi engineering identity | Animated SVG hero |
| Signal worlds | Maps Data & Business Analysis, Technical Solutions and Quality Engineering | Interactive visual deck |
| Cursor signal | Makes exploration feel responsive and intentional | Live cursor-reactive interaction |
| Signal Runner | Provides an engaging project entry point | Linked game experience |
| Profile bridge | Connects the portal to the public GitHub profile | Main profile CTA |

## Engineering focus

The portal is designed to communicate a practical technical identity across:

- business and data workflows
- technical troubleshooting and solutions
- quality engineering and validation
- automation and process improvement
- full-stack systems and responsive delivery

## Validation checklist

Before publishing a portal change:

- hero SVG loads without broken references
- all internal assets resolve from the deployed base path
- identity text remains readable at desktop and mobile widths
- cursor-reactive behavior has a reduced-motion fallback
- buttons and links have visible focus states
- live portal and Signal Runner links open correctly
- the main profile link remains valid
- no portrait or identity asset is unintentionally cropped
- GitHub Pages deployment completes successfully

## Deployment

The live portal is published through GitHub Pages:

- [Open Project Multiverse](https://lokrajjoshi.github.io/multiverse-portal/)
- [Open main profile](https://github.com/Lokrajjoshi)

The repository is intentionally separate from the profile README so the interactive experience can evolve without destabilizing the profile presentation.

## Scope of this repository

This project owns the live interactive portal and its visual assets. The profile README links to it as an entry experience; it does not attempt to reproduce JavaScript cursor tracking inside GitHub-rendered Markdown.
